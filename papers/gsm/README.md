# GSM Engineering Outcomes Paper — public Pages copy

This directory holds only public publication assets, separate from the GSM development repository.

- `index.html`: inline browser PDF viewer.
- `GSM-Engineering-Outcomes-Paper.pdf`: public PDF.

## Updating manually (GitHub Free)

Build the PDF from a local GSM checkout:

```sh
make -C docs/arvix-paper
```

Upload/replace `papers/gsm/GSM-Engineering-Outcomes-Paper.pdf` in this **public** repository, then commit to `main`. Pages will republish the updated PDF. The development repository may remain private.

Page (if this repo is served from the `main` branch root):

https://geniusventures.github.io/gnus.github.io/papers/gsm/

Direct PDF:

https://geniusventures.github.io/gnus.github.io/papers/gsm/GSM-Engineering-Outcomes-Paper.pdf
